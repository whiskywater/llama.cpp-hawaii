# Contributing

This repository is an independently maintained downstream of [ggml-org/llama.cpp](https://github.com/ggml-org/llama.cpp), not an upstream project or endorsed fork. See [README.md](README.md) for the hardware scope and support status.

Contributions should include a clear reason, focused changes, and validation results. Keep architecture-specific work scoped to the relevant backend and preserve behavior on other devices. Distinguish compile-time support from runtime testing, and never claim hardware validation without evidence.

AI-assisted implementation and autonomous validation are allowed here. Contributors remain responsible for understanding, reviewing, and maintaining the changes. Do not include private logs, model files, build artifacts, machine details, local paths, credentials, or unrelated project data.

Keep upstream license files, copyright notices, attribution, and third-party notices. Do not push downstream work to `ggml-org/llama.cpp` or open upstream pull requests from this repository.

The upstream agent and contribution guidance as it existed at the base revision is retained in [docs/UPSTREAM-AGENTS.md](docs/UPSTREAM-AGENTS.md) and [docs/UPSTREAM-CONTRIBUTING.md](docs/UPSTREAM-CONTRIBUTING.md) for historical reference only; it does not govern this downstream repository.
